# Kiara Lam — Marketing Portfolio

GitHub Pages-ready personal portfolio.

## Customize
- Replace `YOUR_EMAIL@example.com` in `index.html`.
- Replace the placeholder LinkedIn/GitHub links with your profiles.
- Replace the four project `↗` links with actual case-study pages, PDFs, or project folders.
- Add visual work, campaign screenshots, presentation excerpts, and measurable results as case studies develop.

## Publish on GitHub Pages
1. Create a public repository such as `marketing-portfolio`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch → main → / (root)**.
5. Save and open the generated Pages URL.

## Suggested structure
```
/
├── index.html
├── style.css
└── projects/
    ├── teen-feed/
    ├── lego-russell/
```

The site intentionally keeps personal-life details out of the public portfolio while using the professional themes that make Kiara's story distinctive.
